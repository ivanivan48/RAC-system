# Работа с репозиторием

Основная ветка - `main`. Каждый участник работает в собственной локальной копии под своим именем в Git. Перед новой задачей обновите `main` командой `git pull --ff-only` и создайте тематическую ветку, например `docs/pz4-uc04`.

В одном коммите фиксируйте одно содержательное изменение. Сообщения коммитов пишите по-русски. Перед коммитом просмотрите список файлов и подготовленную разницу командами `git status` и `git diff --staged`.

В Pull Request укажите цель, связанные требования и сценарии, затронутые файлы и способ проверки. Другой участник просматривает изменения и оставляет содержательный отзыв до слияния. После слияния обновите локальную `main`.

Содержательные изменения отчётов вносите в Markdown. Обновляйте соответствующий DOCX после согласования и до сдачи. Автор проверяет свой DOCX, а ответственного за общий DOCX команда определяет до экспорта. Исходник и изображение диаграммы обновляйте одновременно. Перед сдачей сверяйте текст, таблицы и рисунки в обеих версиях.
