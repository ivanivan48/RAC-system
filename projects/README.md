# Программная часть

В [src](src/) будет размещён исходный код веб-системы. В [docs](docs/) будут храниться сведения о её реализации, настройке и запуске.

На этапе ПЗ № 4 в обоих каталогах есть файлы `.gitkeep`, которые сохраняют структуру при клонировании. Материалы проектирования и отчётность находятся в [общем отчёте](../docs/README.md).
