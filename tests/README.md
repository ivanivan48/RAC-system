# Проверки

В этом разделе будут размещаться тестовые случаи и автоматические тесты после реализации функций. Основанием для проверок служат требования и сценарии из [общего отчёта](../docs/README.md).

На этапе ПЗ № 4 предусмотрена проверка структуры репозитория, относительных ссылок, открываемости исходников UML и соответствия отчётов Markdown и Word.
