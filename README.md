# RAC-system

RAC-system — проект веб-системы интеллектуального подбора сельскохозяйственной техники. Сервис предназначен для фермеров, представителей агрохолдингов и других сельскохозяйственных предприятий.

Пользователь указывает нужную технику и объём обрабатываемых земель. Система уточняет параметры запроса, предлагает подходящие позиции и позволяет изучить их характеристики и цены. В проекте предусмотрены каталог с фильтрами, история подбора и переход к оформлению заявки на покупку или лизинг.

На текущем этапе описаны требования, варианты использования и UML-модели. Реализация запланирована на следующих этапах.
